La puntuación del pádel es la misma que la del tenis, con una diferencia que genera casi todas las discusiones en la cancha: qué se hace cuando el game llega a 40-40. Acá va todo en orden, de lo más chico a lo más grande: punto, game, set y partido.

## Los puntos: 15, 30, 40 y game

Cada game arranca 0-0 y los puntos se cuentan así:

| Puntos ganados | Se canta |
|----------------|----------|
| 0 | Cero |
| 1 | 15 |
| 2 | 30 |
| 3 | 40 |
| 4 | Game |

El marcador se canta siempre empezando por la pareja que saca. Si los que sacan ganaron dos puntos y los que restan uno, es "30-15".

Para ganar el game hay que ganar cuatro puntos, salvo cuando las dos parejas llegan a tres puntos cada una. Ese 40-40 se llama **deuce** o iguales, y es donde aparecen las variantes.

## Qué pasa en el 40-40

Hoy conviven tres sistemas. Antes de empezar un partido conviene acordar cuál se usa.

| Sistema | Qué pasa en 40-40 |
|---------|-------------------|
| **Ventaja** | Hay que ganar dos puntos seguidos. El primero da la ventaja; si se pierde el siguiente, se vuelve a iguales, sin límite de veces. |
| **Punto de oro** | Se juega un único punto y el que lo gana se lleva el game. La pareja que resta elige de qué lado recibir. |
| **Star Point** | Se juega con ventaja normal hasta dos veces. Si se llega al tercer deuce, se define con un único punto. |

La ventaja es el sistema clásico. El punto de oro se popularizó en el circuito profesional a partir de 2020 y se usa mucho en partidos amateur por una razón práctica: los games no se alargan y el turno de cancha alcanza. El Star Point es el sistema que la FIP aprobó para el circuito profesional desde 2026, y lo explicamos en detalle en [Star Point: la nueva regla del pádel](/blog/star-point-nueva-regla-padel).

## Cómo se gana un set

Un set lo gana la primera pareja que llega a **seis games con dos de diferencia**.

- Con 6-4 o 6-3, el set está terminado.
- Con 5-5 se sigue jugando: si una pareja gana los dos games siguientes, se lleva el set 7-5.
- Con 6-6 se juega un **tiebreak**.

## Cómo funciona el tiebreak

El tiebreak es un game especial que define el set, y se cuenta distinto:

- Los puntos se cuentan de a uno: 1, 2, 3, y así.
- Gana la primera pareja que llega a **siete puntos con dos de diferencia**. Con 6-6 se sigue hasta que alguien saque dos de ventaja: 8-6, 9-7, lo que haga falta.
- El set queda 7-6 para quien gana el tiebreak.

El saque también cambia:

1. El jugador al que le tocaba sacar hace **un solo saque**, desde el lado derecho.
2. Después saca la otra pareja **dos puntos seguidos**, empezando desde el lado izquierdo.
3. A partir de ahí se alternan de a dos saques por jugador, respetando el orden que venían usando en el set.

Durante el tiebreak se cambia de lado **cada seis puntos**.

## Cuántos sets tiene un partido

Un partido oficial se juega al **mejor de tres sets**: gana la pareja que se lleva dos.

En partidos entre amigos es habitual acortar el formato para que entre en el turno: un solo set, sets a menos games, o un tiebreak largo en lugar del tercer set. No hay problema mientras se acuerde antes de empezar.

## Cuándo se cambia de lado

Las parejas cambian de lado cuando la **suma de games del set es impar**: después del primer game, del tercero, del quinto, y así. El objetivo es repartir el sol, el viento y cualquier diferencia entre los dos lados de la cancha.

## Quién saca

- El saque cambia de pareja en cada game.
- Dentro de cada pareja, los dos jugadores se turnan. Cada jugador saca un game de cada cuatro.
- El orden de saque elegido al comienzo del set se mantiene hasta que el set termina. En el set siguiente se puede cambiar.

## Llevá la cuenta sin discutir

Entre los cambios de saque, los iguales y los cambios de lado, es fácil perder la cuenta, sobre todo en el tercer set.
